# برنامج مؤتمر 2026 — موقع ثابت

موقع صفحة واحدة (Single Page) خفيف، responsive، RTL، مصمّم للاستخدام من الهاتف أثناء مؤتمر مدته 3 أيام.
لا backend، لا build، لا npm — ملفات ثابتة فقط.

## الملفات

```
index.html      البنية والأقسام
styles.css      نظام التصميم (كل الألوان في CSS variables أعلى الملف)
script.js       البيانات + محرّك البرنامج (كل بيانات المؤتمر في const conferenceData)
assets/icons/favicon.svg
```

## التشغيل محليًا

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا بسيطًا:

```
python -m http.server 8000
```

ثم زر `http://localhost:8000`.

## النشر على GitHub Pages

1. أنشئ repository (مثلاً `conference-2026`) وارفع كل الملفات في الجذر.
2. Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **/ (root)** → Save.
3. الرابط الناتج ثابت طوال المؤتمر — ضعه في QR Code واحد.

كل المسارات نسبية (`./styles.css` …) لتعمل تحت مجلد فرعي.

## تعديل البيانات

كل شيء في أعلى `script.js` داخل `conferenceData`:

- `days[].sessions[]` — الأنشطة. الأوقات بصيغة 24 ساعة `"HH:MM"` (يُقبل `"24:00"` = منتصف الليل). الحقول `end` / `desc` / `location` / `teamId` اختيارية (`null` أو محذوفة).
- `teams[]` — الخدام. المجموعة بدون أسماء تُترك `members: []` ولا تُعرض أسماء مخترعة.
- `topics[]` / `venues[]`.

### ملاحظات على البيانات (غير مُخترعة)

- تاريخ اليوم الأول مؤكد: الأربعاء 2/9/2026.
- تاريخا اليوم الثاني والثالث مُستنتجان من التسلسل (`2026-09-03` / `2026-09-04`) ويُستخدمان داخليًا فقط لتحديد "اليوم الحالي"؛ لا يُعرضان كتاريخ كامل (`dateConfirmed: false`). عند تأكيدهما من المنظم، عيّن `displayDate` و`dateConfirmed: true`.
- مجموعة 5 (الشبع في الصلاة): الموضوع موجود، الأسماء غير متوفرة — تظهر بدون قائمة أسماء.
- الأوقات في المصدر (Excel) بلا AM/PM؛ طبقة العرض `formatTime()` تعرضها بصيغة ص/م حسب سياق البرنامج دون تعديل البيانات المصدرية.

## تحديد النشاط الحالي

يعتمد على ساعة جهاز المستخدم (`new Date()`) لا على الخادم. يُعاد الحساب عند التحميل، وكل ~45 ثانية، وعند العودة إلى التبويب.
